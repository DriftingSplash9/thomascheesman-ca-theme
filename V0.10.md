## What's been built / polished this session

### Desk-menu BHAG polish
- Hotspot styling overhauled: dropped the 4-direction `drop-shadow` silhouette outlines and the firefly halo glow ring; replaced with an iridescent oil-slick sheen sweep (lavender → cyan → white → gold → rose) masked to the PNG silhouette via `mask-image`. Cycle 20s with `--hot-x` + `--hot-y` 2D-scatter stagger so objects flash randomly rather than as a wave.
- Synchronized brightness pulse on the PNG itself (`tc-desk-glow-pulse`) so objects visibly light up when the sheen crosses center.
- 3D mouse-tracking tilt on hover via `--tilt-x` / `--tilt-y` CSS vars driven by `wireHotspotTilt()` in `assets/js/desk-menu.js`. Each PNG leans toward the cursor.
- Hover lift bumped 1.15 → 1.35 scale, no cartoony scaling beyond that.
- Card occlusion fix: `.tc-desk__hotspot:hover { z-index: 10 }` so the hovered hotspot's card sits above later DOM-order siblings.
- Mouse hotspot remains the cursor-trail easter egg (no PNG → no sheen).

### Alberta crest video easter egg
- Clicking Faith's Alberta crest opens a new drawer (`#tc-desk-crest-drawer`) that plays one of two videos (IMG_4119.mov / IMG_4109.mov).
- Each click alternates to the other via `localStorage` key `tcDeskCrestLast`.
- Pauses + rewinds when drawer closes (MutationObserver on `.is-open`).
- Wiring in `wireCrestVideo()` inside `assets/js/desk-menu.js`.

### Desk arcade (six games, hidden behind the toad)
Lives in `assets/js/desk-games.js` and `#tc-desk-games-drawer` markup in `inc/desk-menu.php`. Clicking the toad (`#tc-desk-frog`) opens it.

Games:
1. **Snake** — 22×20 grid, gradient body, speeds up per food.
2. **Pong** — first-to-5 vs CPU with random-offset tracking error so the CPU is beatable. Ball trail.
3. **Pac-Man** — 12-row maze with ghost-box openings top + bottom (originally the ghosts were sealed in), 2-4 ghosts, level progression on clear.
4. **Asteroids** — wrapping field, rotate/thrust/fire, explosion particles, +1 asteroid per wave (cap 9).
5. **Brickles** — Breakout clone, brick-shatter particles with gravity, ball speeds 12% per cleared wall.
6. **Solitaire** — Klondike, draw-one, click-to-select / click-to-place (no drag-drop).

Chrome:
- Retro CRT TV bezel: wood-tone gradient + scanlines overlay + pulsing red power LED + "TC · ARCADE" nameplate. `width: fit-content` so each game's bezel is the right size for its canvas.
- Fullscreen button (top-right of bezel) using the Fullscreen API. In fullscreen the bezel is dropped, canvas scales to `92vh` with `image-rendering: pixelated`.
- "Close arcade" button (top-left, only visible in fullscreen) — exits fullscreen AND closes the drawer in one click.
- Game-over overlay with name-entry form (only shown when score qualifies for top-10) + mini-leaderboard with "Xd ago" timestamps.
- Cursor restored across the entire drawer + the fullscreen wrap (overrides the sitewide `html.cursor-custom *` rule).
- Game keydown handlers `return` early when typing in a form input (fixes a/w/s/d being swallowed in the name field).

### REST-backed leaderboards
- New endpoint at `/wp-json/tc-games/v1/scores` in `inc/games-leaderboard.php`. GET returns all six boards (top-10 each); POST writes a `{game, name, score}` row.
- Storage: one WP option per game (`tc_games_scores_<game>`). No new DB tables.
- Public read AND public write. Anti-cheat is open by design — anyone with browser tools can POST any score. Acceptable for a hidden personal-site arcade. Bare hardening in place: game key whitelisted, name stripped of HTML and capped at 16 chars, score capped at 9,999,999.
- JS-side caching: `boards` object in `desk-games.js` is session-cached, refreshed on drawer open + after every score submission.
- `wp_localize_script('tc-desk-games', 'tcDeskGames', { scoresUrl })` exposes the REST URL.

### Sitewide image treatment (gallery-glass frame)
- One unified look replacing per-section flourishes (the old `.tc-photo-gallery__item` scale 1.04 + amber accent ring is gone). 4px rounded corners, 1px inset highlight at the top edge, soft drop shadow. Hover: 3px lift (no scale), +6% brightness, +5% saturation, deeper shadow. 360ms cubic-bezier easing.
- Scope: `.wp-block-image img`, `.wp-caption img`, `.entry-content img`, `.tc-photo-gallery img`. Excluded: desk-menu hotspots (CSS background-images, not `<img>`), site logo / nav, PhotoSwipe lightbox UI.

- Home-page reveal animations (pillar tumble + blog-card random tumble) disabled per Thomas: "I just want the simple images with none of that."
- `.post-card` hover simplified: lift -3px, no img scale, no cyan glow — matches sitewide treatment.

## Known sharp edges

These won't block go-live but are worth noting.

1. **Leaderboards are open-write.** Anyone with browser dev tools can POST a fake score. Acceptable for now per Thomas; if abuse appears, add a nonce or per-IP rate limit in `inc/games-leaderboard.php`.

2. **Game `localStorage` keys** — `tcDeskCrestLast`, `tcCursorTrailSettings`, `tcCursorTrailVariant`. None are PII; mention only because changing them invalidates persisted state.

3. **The `-e<digits>.webp` HCS hand photo** is a counter-example to the sitewide memory rule "strip `-e<digits>` suffix." For this specific file on Hostinger, only the edited variant exists (verified with a HEAD). If you re-encounter `-e<digits>` URLs in the wild, always test both before assuming the bare stem works.

4. **Photo gallery counts in `inc/desk-menu.php`** are hardcoded. If you add/remove gallery entries, also bump the count in the slideshow drawer ("X photos" labels) and the "all of us" total.

5. **`build-image-audit.py`, `test-image-urls.py`, `image-audit.xlsx`, `image-audit-tested.xlsx`, `remove-dead-images.py`** are at the repo root, untracked by git. They're dev helpers, not theme code. Either delete them after go-live or add them to `.gitignore`.

6. **`.claude/worktrees/recursing-johnson-f390bc/`** — this is the working tree for the current session. Once main is stable and you've confirmed everything, delete the worktree. The branch can stay or be deleted via `git worktree remove`.
