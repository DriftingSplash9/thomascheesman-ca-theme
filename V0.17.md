## The styling system (the 10 polish items — now automatic for every line)

These shipped in CSS v3 + the converter + the rail JS. A new line gets them **for free**; you only supply content (kickers, pull-quotes, ribbon nodes) in its image map.

1. **Readable text column + media bleed.** Body is a ~52rem reading column centred in the wide (1200px) plate; floats live inside it; the gallery, lineage table, and ribbon bleed wider (`width: min(62rem,92vw); margin-left:50%; transform:translateX(-50%)`).
2. **Pull-quotes.** Per-chapter `pullquote` in the image map → a big italic `.heritage-line__quote` aside after the chapter's first paragraph.
3. **Chapter "fact kicker."** Per-chapter `kicker` (dates · places) renders as a styled line under the chapter title.
4. **Per-line background motif.** A faint woven "tweed" cross-hatch on the glass (`.heritage-line--longread::after`, opacity .05, 7px so it survives the backdrop blur). Re-tintable per line.
5. **Scroll-reveal.** Chapters + figures rise/fade as they enter, via CSS `animation-timeline: view()` — `@supports`-gated and disabled under `prefers-reduced-motion`. (Bleed elements are excluded — they use `transform` for layout.)
6. **Chapter rail.** `initLongreadChapterRail()` builds a slim sticky left-rail from the chapter eyebrows; current chapter lit via IntersectionObserver; smooth-scroll; hidden under 1180px.
7. **Duotone photos.** Gentle `filter: sepia(.26)…` on body figures, full colour on hover; the lightbox shows the untouched original.
8. **Ornamental dividers.** A centred ✦ (`::before`) opens each chapter after the first, replacing the plain rule.
9. **Lineage ribbon.** A horizontal generational spine (name + dates, arrow-linked nodes) above the lineage table — from a `ribbon` array on the "Lineage at a glance" anchor.
10. **Richer hero.** Larger vignetted hero image + an uppercase **kicker** line (`'kicker'` in the registry, e.g. "Eight generations · Donegal to Alberta · c. 1750 – today").

## How to add a new family line's long-read (runbook)

Specific next task is **Haiste**, but every line follows this:

1. **Edit the manuscript.** `{Line}-Story-DRAFT.md` → `{Line}-Story-EDITED.md` applying `Docherty-EDIT-change-log.md`. Regenerate the keepsake docx with `_md2docx.js`.
2. **Gather + identify images.** Thomas uploads to WP Media; list/identify via the **public REST API** (no auth):
   `GET …/wp-json/wp/v2/media?per_page=30&orderby=date&order=desc&_fields=id,source_url,title,alt_text,caption`
   - **URL gotcha:** strip the `-e<digits>` edited-suffix; use the **bare stem**. `-scaled.jpg` often 404s while bare `.jpg` is 200 — HEAD-check each (`curl -sI -o /dev/null -w "%{http_code}"`).
   - **Sideways scans:** determine the fix by rotating a local copy and re-reading (90° CW that comes out upside-down ⇒ correct is **CCW**). Set `"rotate":"ccw"|"cw"` on the figure. The converter wraps it; CSS re-orients the box (assumes ~16:9 source — `aspect-ratio:1238/2200`).
3. **Author `{line}-images.json`** (schema below) — figures, gallery, plus **kickers, pull-quotes, and the lineage ribbon**. Run `_md2heritage.js` → `inc/heritage/{line}-story-body.php`.
4. **Register the line** in `page-story.php` (`$tc_longread_registry`, keyed by parent spoke slug): `slug, eyebrow, title, subtitle, kicker, spoke_url, spoke_label, hero_image, hero_alt, body`.
5. **Add the palette** in `style.css`: `.heritage-longread--{slug} { --blob-a/b/c: …; }`. `--line-color` for the 5 spokes is already mapped (Cheesmans `#22D3EE`, Dochertys `#EC4899`, Lakemans `#10B981`, Rycrofts `#F59E0B`, Haistes `#6366F1`); you add only the three **blob** colours. Docherty's are Gaelic (slate-blue `#34596b` / peat-heather `#6e4a78` / moss `#4f6b3e`). Give each line a thematic trio (Haiste → Yorkshire moor: heather/coal-grey/wool-gold; Lakeman → Dutch water: canal-blue/tulip/polder-green).
6. **Link the spoke:** add the `.heritage-line__readmore` block to `inc/heritage/{line}-body.php` (copy Docherty's).
7. **Bump `style.css` Version** (Edit tool, not `sed`).
8. **Create the WP page:** Title **"Story"**, slug **`story`**, **Parent = the line's spoke page**, **Published** (manual wp-admin step, or guide Thomas).
9. **Propose commit, wait for "go," push.** Remind Thomas: **LiteSpeed → Purge All** + hard-refresh.

### Image/content-map schema (`{line}-images.json`)

Keys are **chapter eyebrows verbatim** (`"Prologue"`, `"Chapter Five"`, `"Lineage at a glance"`, `"Appendix: The wider family"`…). `kicker` renders under the title; the rest inject after the chapter's first paragraph.

```json
{
  "Chapter Five": {
    "kicker": "1872–1959 · Hamilton → Illinois → Alberta",
    "pullquote": "The reversal of two centuries of dispossession.",
    "figures": [ { "path": "2026/05/IMG_4532.jpg", "alt": "…", "caption": "…", "float": "right", "rotate": "ccw" } ]
  },
  "Lineage at a glance": {
    "ribbon": [ { "name": "Robert", "dates": "1872–1959" }, { "name": "…", "dates": "…" } ]
  },
  "Appendix: The wider family": {
    "figures": [ { "path": "…", "float": "right" } ],
    "gallery": { "title": "The family album", "items": [ { "path": "…", "alt": "…", "caption": "…", "rotate": "ccw" } ] }
  }
}
```
- `float`: `"left"|"right"` or omit (centred). `rotate`: `"ccw"|"cw"` for sideways scans.
- Galleries open in the **sitewide PhotoSwipe lightbox automatically** (it wraps every `<main> img`).
- `pullquote` should be a punchy line that also appears in the prose (it's an aria-hidden visual echo).
- `kicker` = dates · places. The **hero** kicker is separate — it lives in the registry, not here.

## Architecture notes / sharp edges

1. **`get-page` (MCP ability) returns "Page not found" for a NESTED page** — it looks up by leaf slug. The Docherty story page IS live (id 2502, parent 2453). Verify nested pages via `list-pages` or REST `?slug=story&_fields=id,link,parent`.
2. **Z-order:** global WebGL canvas `z:-1` → the long-read's fixed atmosphere `z:0` (a deep per-line base gradient + 3 morphing blobs; **base gradient is what re-colours the page**, not faint blobs) → content `z:1`. The frosted plate `backdrop-filter`s the atmosphere through the glass.
3. **Chrome frame** is on the `.heritage-longread__frame` wrapper (the plate's own `::before`/`::after` are taken by the ghost numeral and the now-repurposed motif). `::before` = static brushed-metal ring (mask-composite border, 3.75px); `::after` = an always-on **iridescent shimmer** (`background-position` drift 11s + `hue-rotate` 7s, coprime → ~77s non-repeat).
4. **Motif must stay coarse (~7px)** — finer lines are erased by the plate's backdrop blur. It lives on `.heritage-line--longread::after` (z:0) with the body at `z:1` above it.
5. **Media bleed uses `transform: translateX(-50%)`** — so do NOT add the scroll-reveal `transform` animation to gallery/table/ribbon (they're excluded). Scroll-reveal also requires `animation-timeline: view()` (Chromium/modern; older browsers just show content).
6. **Chapter ids** are slugified from the title (`lr-…`); the rail and any in-page anchors depend on them.
7. **Rotation CSS assumes ~16:9 source.** Different aspect ⇒ adjust `.heritage-longread__rot` `aspect-ratio`.
8. **TOC dot:** `initHeritagePage()` appends a `.heritage-toc` to `<body>` (one dot per `.heritage-line`); the long-read's single section made an orphan dot — hidden via `body:has(.heritage-longread) .heritage-toc`. The top `.heritage-progress` bar is kept. (`:has()` = modern browsers; graceful otherwise.)
9. **Line coverage:** Haiste & Lakeman have a spoke + a draft (ready). **McIver has a manuscript but NO spoke** (its thread lives in the Docherty spoke) — a McIver long-read needs its own spoke page + an accent colour first. **Cheesman & Rycroft have spokes but no manuscript.**
10. **🔒 Privacy / the Living Line:** Thomas made an explicit, informed choice to **keep** the line naming his and Melanie's 2016 marriage on the public Docherty page. Don't second-guess it. For other lines, surface couple-framing for his call rather than deciding.
