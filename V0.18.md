## The map — research & recommendation

**Direct answers to Thomas's questions:**

1. **"Is there a cool map system we can adopt and modify?"** Yes. There's nothing reusable in the theme today (the old `/timeline` map is parked and was a bespoke single-person thing). Pick a real library:
   - **Leaflet** (free, no API key, tiny) — fastest to stand up; pan/zoom; great plugin ecosystem. Good if Thomas wants an interactive slippy map.
   - **D3-geo + a world TopoJSON** (SVG) — most *stylized & animatable*; you can literally **animate a route drawing itself** across the map (stroke-dash), theme it to match the site's glass/atmosphere look, and colour-code freely. Best for the "keepsake, cinematic" feel. **Recommended primary**, optionally over a muted Leaflet/static base if pan-zoom is wanted.
   - Useful Leaflet plugins if we go that route: **Leaflet.Arc** (great-circle arcs between points), **leaflet-ant-path** (animated flowing migration lines), **leaflet-timedimension** (a time slider that reveals features by year).
2. **"Does the map allow a path between points, or just highlight points?"** **Both.** Every option above draws **lines/paths between points**, not just markers — Leaflet `L.polyline` / great-circle arcs, or D3 line/`geoPath` with animated stroke. So we can absolutely connect a family's stops in order and **animate the journey over time**.

**Proposed data pipeline (matches Thomas's "one xlsx per family" plan):**
- One spreadsheet per line. Columns: `family, person_or_group, event, place_name, lat, lng, year_start, year_end, note`. (Geocode place names → lat/lng once; many are already in the manuscripts.)
- Convert each xlsx → **GeoJSON**: a **Point** per stop + a **LineString per family/person** ordered by year. Colour by family — reuse the existing `--line-color` palette (Cheesmans `#22D3EE`, Dochertys `#EC4899`, Lakemans `#10B981`, Rycrofts `#F59E0B`, Haistes `#6366F1`; assign the orphans McIver/Verboom/Steinke their own).
- A **year scrubber** animates appearance over time; all paths **converge on Alberta** (Calgary/Grande Prairie) — the visual payoff.

**Suggested phasing (plan-and-propose each):**
- **P1** — static, colour-coded points + arcs for all families (proof of concept on one or two lines first).
- **P2** — time-slider animation (paths draw as the year advances).
- **P3** — narrative integration: tooltips/markers link into the relevant long-read; a companion **unified "all rivers converge" essay** drawing on [Family-Intersection-Bible.md](../Heritage%20research/Family-Intersection-Bible.md) (which already sketches the confluence).

This is a large, multi-session feature; treat each phase as its own plan → approval → build.
