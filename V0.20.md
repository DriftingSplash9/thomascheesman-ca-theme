## Key systems / conventions added (so the next agent isn't surprised)

1. **`page-thomas.php`** reuses the `/about`+`/hcs` essay chrome (`.about-section`, `.about-figure`) plus a scoped **`.thomas-page`** block in `style.css` (frosted plate, candle-flame headings/brows, era eyebrows, folds, CTAs, gallery, left TOC). Chapter prose is inline (like /about, /hcs).
2. **Thomas-page photos** live in **`assets/img/thomas/`** (theme-hosted, optimized with PIL max-1600px q82, slug names). **Inline figures** are referenced by name via `tc_thomas_fig()`; the **gallery globs every `g-*.jpg`** + a `$thomas_caps` caption map (identifiable ones captioned, the rest blank). To add a gallery photo: optimize → drop `g-<slug>.jpg` in the folder → it appears. To remove one: `git rm` the file.
3. **WebGL per-page palette hook (new, generic):** `initWebGLBackground()` now reads `--webgl-tint` (falls back to `--line-color`) and `--webgl-accent` (defaults to cyan). Any page can theme its background in two CSS lines via `body:has(.<page-class>) { --webgl-tint / --webgl-accent }`.
4. **Family tree now has a trunk tier:** `tree-chip--trunk tree-chip--thomas` between the 8 branch chips and the 3 kid roots. Melanie's chip will join it (positions left room — Thomas centered at left:50%; nudge to ~40% when Melanie is added).
