## 🩹 Sharp edges this thread

1. **The converter must run from `Heritage research\`** (`cd` there first) — `_md2heritage.js` resolves the images.json relative to cwd, and the Bash tool's cwd resets between calls; use `git -C <repo>` for the verification diffs in the same call.
2. **Word-diff is the right regen check:** `git diff --word-diff=plain <body.php> | grep -oE '\[-.{0,60}'` — if the only removed segment is the insertion-point boundary, the pipeline stayed idempotent. Used on all seven; all clean.
3. **Edit tool on off-repo jsons requires a Read first** (tool guard) — reading via `node -e` doesn't count.
4. The old "Married in Teepee Creek" passport copy is **gone from the repo** (passport page retired) — no venue discrepancy exists; all manuscripts say Calgary, 2 July 2016.
5. Lakeman json key `"Interlude — The Verbooms"` does **not** match the md header (`Interlude — Suzanna's people, the Verbooms`), so its kicker/pullquote never render. Pre-existing, harmless, worth fixing on the next Lakeman touch.
6. **Equal-specificity default blocks must precede their per-line overrides.** `.heritage-longread { --blob-* }` vs `.heritage-longread--{line} { --blob-* }` are both 0,1,0 on the same element — only source order decides. The default sat last and silently won for who-knows-how-long. When adding any new "default + modifier" variable pattern, put the default FIRST, and verify with `getComputedStyle` on the live page, not by eyeballing the colour.
7. **Live-verify with computed styles, not screenshots alone.** The Cheesman page looked "wrong-coloured" for two stacked reasons (stale `?ver` HTML racing the deploy + the cascade bug); `getComputedStyle(...).getPropertyValue('--blob-a')` in the browser console separated them in one call.
