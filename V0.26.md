## What the site IS now (the whole picture)

A bespoke Astra **child theme** for a pages-only personal site — no blog. Six worlds:

1. **The desk metaphor nav** (the original BHAG) — Thomas's actual desk photo with hover hotspots over real objects; keyboard→search, etc. Plus a **plain desktop menu** and a **mobile accordion** (three menus total). `inc/desk-menu.php` + `assets/{css,js}/desk-menu.*`.
2. **The Drawer footer + the Secret Drawer puzzle** — a sitemap drawer that opens into an 87-item point-and-click puzzle (3 prize endings, email alerts, a pinball easter egg, the desk arcade's 6 games, a Pac-Man/Hangman/clicker). `footer.php`, `assets/js/{desk-drawer,secret-drawer,drawer-engine,desk-pinball,desk-games}.js`, `inc/data/drawer-puzzle.json`.
3. **The eight heritage long-reads** — book-length family histories (Cheesman, Docherty, McIver, Lakeman, Verboom, Rycroft, Steinke, Haiste), each with a descent **tree**, its own **pastel**, a per-line **WebGL atmosphere**, kickers/pull-quotes/figures, a Notes appendix, and (Haiste/Lakeman) a YouTube **film reel**. Generated from off-repo markdown by `_md2heritage.js`.
4. **The person pages** — Thomas ("Thomasito"), Patience, Faith, Daniel: first-person illustrated long-reads with per-page WebGL, candle-flame headings, chapter rails, galleries. Melanie's is the **one still unbuilt** (draft exists).
5. **The Lanterns of Record map** — `/family/heritage/map/`, a D3-geo "light-table": every family record as a lantern, great-circle migration trails, a time cursor (1610→2030), a ghost descent-tree, all converging on Alberta. Data pipeline: `family-map-data.xlsx` → `_xlsx2map.py` → `inc/data/family-map.json`.
6. **WP 7.0 autonomous controls** — an `agent_page_editor` role + MCP Abilities (`tc-portfolio/*`: list/get/update pages, create-page, quotes, leaderboard) via the MCP Adapter plugin, wired to Claude Code's `thomascheesman` MCP server.

Plus: header weather capsule (Open-Meteo), daily quote/riddle, rot13 email, AIOSEO meta descriptions for every page, VideoObject schema, Bing verification, the Case Studies + HCS pages, BYR/GPRS cross-links.

## The systems a new agent must know (durable architecture)

1. **Heritage long-reads.** `{Line}-Story-EDITED.md` (Rycroft & Steinke are `-DRAFT.md`) + `{line}-images.json` in `Heritage research\` → `node _md2heritage.js <md> <out.php> "<Label>" <json>` → `inc/heritage/{line}-story-body.php`. Labels: Lakeman=`"Lakeman"`, Verboom=`"Verboom"`, rest `"The X"`. The json keys figures/pull-quotes/kickers/`tree`/`video` **to the literal chapter-heading text** — a merge or rename without the matching json re-key silently drops that chapter's chrome. Single-`##` sections key by title (eyebrow is empty). **Verify with grep, not `git diff --stat`** (bodies are a few very long lines → big prose changes show as ~1 changed line). Chrome = `inc/page-heritage-longread.php`; hub-line dispatcher = `page-story.php` (registry); orphan/nested lines = standalone `page-{slug}.php` (mcivers→docherty, verbooms→lakeman, steinkes→rycroft).

## 🩹 Sharp edges (the permanent ones; full lists live in V0.16/21/24)

- **Converter smart-quotes apostrophes** (`Ric's`→`Ric&rsquo;s`) and **auto-links "Notes"** → a grep on those phrases falsely returns empty. Anchor verification on apostrophe-free spans.
- **Generated bodies are few-but-very-long lines** → `git diff --stat` understates prose changes; verify with grep, and word-diff (`git diff --word-diff=plain`) to confirm the converter stayed idempotent.
- **Chapter merges/renames need the images.json re-key in the same regen**, or kickers/pull-quotes/figures silently drop. Collision-safe renames: delete orphaned keys first, then rename survivors in file order.
- **The converter runs relative to `Heritage research\`** for `_image-dims.json`/jsons; the Bash cwd resets between calls — pass absolute paths or `cd` in the same call. Edit tool on off-repo files needs a Read first.
- **Cross-link "the Verboom story" NOT FOUND on Lakeman regen is harmless** — the phrase only lives inside the Suzanna-chapter CTA (an explicit link).
- **LiteSpeed cache** is the #1 "did it deploy?" trap — Purge All after every push; bust HTML with `?cb=N`, image-load fixes with `?v=<ver>`.
- **Version bump = Edit tool only** (sed/PowerShell corrupt line endings/BOM). **Never `git add .`** (scrapes + docx + raw clips in the tree).
- **Live-verify colours with `getComputedStyle`, not screenshots** (stale `?ver` HTML races deploys; equal-specificity cascade bugs hide). **Video playback can't be verified in an automated browser** — trust byte inspection or Thomas's eyeball.
- **bash heredocs mangle backslashes / choke on long content** — write Python helpers to a file (forward-slash paths) and run them.
- **Genealogy decoys are everywhere** — anchor on birthplace+year+household, tier every claim (VERIFIED/PROBABLE/LEAD), never write tree-tier claims as fact.
