## The keepsake-PDF system (durable architecture, new this thread)

Three parts (full detail in the memory `project_tc_keepsake_pdfs.md`):

1. **`assets/css/print.css`** — enqueued site-wide as `media="print"` (handle `tc-print`, in `functions.php`). Neutralises the dark theme to dark-ink-on-white, promotes the page hero into a **cover page**, styles chapters / dek / pull-quotes / the **descent tree** (linearised, facts forced open) / the **lineage ribbon** (wrapped) / the **lineage table** (fit) / the Notes appendix (opened). **Photos are currently hidden** (`#primary figure, #primary img { display:none }`) — the keepsakes are text + the genealogy "flow charts." Scoped to `#primary`. Also makes anyone's on-page **Ctrl+P** print cleanly.
2. **`build-keepsake-pdfs.py`** (repo root, **gitignored**) — Playwright headless Chromium drives the live URLs, **injects print.css directly** (so generation doesn't need a deploy), opens `<details>`, renders to PDF with a page-number footer + a heading-built outline, then cleans the outline titles with PyMuPDF. Run: `python build-keepsake-pdfs.py` (all) or `… faith cheesmans` (subset). Output → `keepsake-pdfs/` (gitignored), ~0.1–0.5 MB each. `EMBED_IMAGES=False` flag skips the (built but dormant) Pillow image-downscale pass — flip to `True` when images return.
3. **On-site Download buttons** — **not yet wired.** Plan (Thomas's earlier choice): host the finished PDFs in **WP Media** (he uploads), link lineage buttons publicly; kids' buttons held until the family login. Pending: he uploads + sends one File URL so the path pattern is known, then the buttons get wired.

**Hard-won print gotchas (all fixed; don't reintroduce):**
- The frosted plates' `backdrop-filter: blur() brightness(0.5)` flattens into **opaque transparency groups in print that painted over chapter headings** → kill `backdrop-filter`/`opacity`/`mix-blend-mode` on every `#primary` element + pseudo.
- The horizontal **lineage ribbon** (`overflow-x:auto`, ~1650px) made Chrome **scale the whole page down ~0.67×** → let it `flex-wrap`; force the lineage **table** to `table-layout:fixed;width:100%`. Any over-wide element triggers the same scale.
- Chrome's print engine lets a **multi-line chapter heading's last line overflow its box**, so the dateline kicker overlapped it → generous kicker `margin-top` + `break-inside:avoid` (keep the title whole; a title split across a page break dropped its last line under the kicker) + `break-after:avoid`.
- **Verify visually with PyMuPDF (`fitz`)** rendering pages to PNG — **poppler/pdftoppm is NOT installed**, so the Read tool can't open PDFs directly. Sanity scripts used: count `type==1` blocks per page (covering groups, want ~0; only the drop-cap remains), and per-line worst title→kicker gap (want ≥ +5px).
- A **`keepsake-complete.pdf`** in the folder is **Thomas's own Acrobat "combine" of the OLD files — stale.** Offer to add a proper merged-book output to the generator if he wants one combined PDF.
