## 🩹 Sharp edges (reaffirmed / new this thread)

- **Self-purge ability** is the happy path now — but it can't clear the combined CSS/JS optimizer cache (no programmatic LiteSpeed hook exists; verified `has_action` only finds `litespeed_purge_all` + `litespeed_purge_all_object`). For stale combined bundles, the Toolbox CSS/JS purge or a changed enqueue set is needed.
- **Mixed CRLF/LF** (see state note) — detect per file; the Edit tool is fine for single-line, Python with NL-detect for multi-line; never `sed -i` (rewrites all endings).
- **`background-size: cover` exists at `desk-menu.css:1049`** (the mobile blurred desk backdrop) — a deliberate pre-existing exception to the no-cover rule (it's a darkened/blurred backdrop, no composition to crop). Left as-is; flagged so it isn't "fixed" by reflex.
- Standard: LiteSpeed purge after deploy (now via the ability); **explicit `git add` paths** (tree carries `.docx`/`.xlsx`/`.mp4`/loose `build-*.py`); bump `style.css` `Version:` with the **Edit tool** on every theme-code commit (docs/CI don't bump); never `object-fit: cover` (use `contain`); kid-privacy + "parents" not "co-parents"; auto-push is **TC-only**.
