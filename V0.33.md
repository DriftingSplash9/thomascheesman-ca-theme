## ⚠️ Read this first — the big new sharp edge

**The MCP `tc-portfolio/purge-cache` ability does NOT clear LiteSpeed's COMBINED CSS/JS.** Pages load a combined bundle from `/wp-content/litespeed/css/<hash>.css`. After a CSS deploy, the markup goes live immediately (verifiable in HTML), but the *visual* CSS change won't show until the combined bundle refreshes — either on its TTL (a few minutes) or via **wp-admin → LiteSpeed Cache → Toolbox → Purge → "Purge CSS/JS Cache"** (which the API can't trigger). This bit us repeatedly this session — every "is the deploy live?" confusion traced back to it. **Tell Thomas to Purge CSS/JS Cache after CSS-bearing deploys**, or wait for the TTL, then hard-refresh.

Also reaffirmed: the live theme folder is **`tc-ventures-child-theme`** (repo name, not `tc-ventures-child`) — use it for curl asset HEAD-checks. [[reference_tc_live_theme_dir]]
