### PERF-3 — `/hcs` image right-sizing ([inc/photo-gallery.php](inc/photo-gallery.php))
The `/about` + `/hcs` essay templates hard-code media-library URLs in plain `<img src>` tags, which **bypasses WordPress's responsive-image system** — so the browser fetched each full-size original for a figure that displays at ≤320px (floated `.about-figure--left/right`) or ≤480px (`.about-hero-figure`). New helper **`tc_fig_img( $url, $alt, $sizes, $loading )`**:
- Resolves the URL → attachment via the gallery's cached `tc_gallery_attachment_id()`.
- Emits `srcset` + `sizes` + intrinsic `width`/`height`, and hands the lightbox the full file via `data-tc-full*` (honoured by `tcWrapImgForLightbox` in main.js).
- Degrades to a plain `<img>` when a URL has no library attachment (external/deleted/`-e<digits>` edited thumbs) — nothing breaks.
- **Live result: 14/17 figures now serve `srcset`.** The heavy hitters resolved (e.g. `hands-and-xray-scaled.png` was **3.5 MB** full → now offers `242×300`/`768×953`/…; `fall-leaves-scaled.jpg` **1.1 MB** → `225w`/`767w`). The 3 fallbacks are 2 tiny images (64 KB, 20 KB) + the 327 KB closing portrait (below-fold, lazy — negligible; `attachment_url_to_postid()` quirkily misses it despite it being a real attachment).
- The helper is reusable for `/about` if ever wanted (same `.about-figure` chrome).

### Header full-width navigation (the big one)
**Files:** `header.php` (markup), new **`assets/css/header-nav.css`** (enqueued sitewide after `astra-child-style`), `initHeaderNav()` in `assets/js/main.js`, `functions.php` (enqueue). Desk menu **unchanged** — the MENU trigger still opens it.

**What it is (desktop ≥1000px; phones keep today's capsule + mobile accordion, `display:none` below the breakpoint):**
- A contained **~1040px floating bar centred** on screen: `Home · About · HCS▾ · Family▾ · Heritage▾ · Contact · Elsewhere▾`, brand left, weather + MENU right, same frosted glass + rotating cyan **gleam border** (a touch more solid + brighter than the mobile pill).
- **Morph:** on scroll past 80px, a single class `html.tc-head-min` (set by a rAF-throttled scroll listener) animates the bar's `left` + `width` so it **condenses to the top-right corner pill**; re-expands centred at the top on scroll-up. Reduced-motion → instant.
- **Museum-Drawer dropdowns:** frosted trays, staggered item reveal, hover/focus open (CSS) + click/Esc/click-outside (JS disclosure pattern, not `role=menu`). **Heritage** is de-walled: Hub + Map, a rule, then the 8 lines each with a 2px chip in its `--line-color` pastel. **Family** items lift like file-tabs in the kids' colours.
- **Living Border:** the gleam shifts per hovered section — faster on Heritage, calmer on HCS, warmer (gold) on Family. Motion/feel only.
- **A11y:** disclosure buttons, keyboard + Esc, `aria-current` on leaf links, collapsed nav drops out of the tab order (`visibility:hidden` after fade), full reduced-motion fallback.

**Links are hardcoded, mirroring the plain/mobile menus in `inc/desk-menu.php`** — so the nav set now lives in **4 places** (desk/plain/mobile/header). Consistent with how the codebase already works; flagged to Thomas as an optional future DRY cleanup (drive all from one source). A `primary` nav-menu location is registered in `functions.php` but unused.

#### ⭐ Header-nav gotchas (don't regress these)
- **Dropdown trays hang BELOW the bar**, so any `overflow:hidden` ancestor clips them (this was the "dropdowns don't open" bug). The nav is `overflow:visible` **at rest** so trays escape, and clipped **only while morphing** — `.tc-headnav--morphing` (expand) + `html.tc-head-min` (collapse), toggled in `initHeaderNav` with a 650 ms safety timeout — so links never spill mid-animation.
- **The morph can't animate `width` to `auto`**, so `initHeaderNav` **measures the pill width** (persistent items, nav hidden, `.tc-head-measuring` helper) into `--tc-head-min-w` and transitions to that. Re-measures on resize + when the weather temp text changes (MutationObserver) + after `document.fonts.ready`.
- **Tunables (all one-liners in `header-nav.css`):** bar width `min(1040px, …)` + the `left: max(20px, calc(50% - 520px))` centring (keep the half-width in sync, 1040/2=520); the 80px scroll trigger (main.js); morph speed `0.55s`; drawer/stagger timings; Living-Border intensities.
