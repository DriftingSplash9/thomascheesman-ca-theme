## What shipped this session (by theme)

### Graphics arc (1.0.707–715, 722)
- **Bloom + emissive (phase D)**: vendored r128 postprocessing
  (`assets/js/vendor/three-r128-postfx.js` — bundle ORDER matters, see
  header; loaded by back-quarter.js with `?cb=Date.now()` because
  browser cache outlives LiteSpeed purges). Composer = RenderPass →
  UnrealBloom → color-grade ShaderPass; WebGL2-only (multisample RT
  keeps AA); WebGL1 falls back to plain render. Every light is an HDR
  `glow()` material. **Bloom is a NIGHT instrument**: threshold +
  strength follow the day factor (daylight walls must never glow —
  that regression happened once, 1.0.722 fixed it).
- **The painted world (phase 1)**: procedural texture library
  (`cacheTex` + wood/barn/dirt/metal/stone/leaf/grass/brick/plank/
  hide/wool/hay/tread/coin/…), role materials (woodMat/barnMat/…),
  dry-olive prairie palette, violet-shifted shadows, day/night grade.
- **Atmosphere (phase 2)**: `applyAtmosphere()` onBeforeCompile
  injection on every Lambert/Phong — prairie-dust tint near ground +
  distance ground-haze. **Handles instancing** (USE_INSTANCING branch;
  forgetting it washed all instanced plants — fixed). Mud things pass
  `dust=false` or they go pale.
- **Lights warm + dim**: windows glow(0xff9440, 0.95) (sub-1.0 can't
  clip white); lanterns are SPHERES ~1.05–1.15 (boxes read as light
  cubes); headlight spots 0xffb45e/0.72; glowDisc fake pools deleted.
