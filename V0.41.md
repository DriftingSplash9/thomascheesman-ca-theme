## Sharp edges (new + carried)

- **⭐ CRLF hazard for remote/cloud sessions**: this working tree is
  CRLF, the repo stores LF. A git client with `autocrlf` unset sees
  every text file as modified and will happily commit a
  whole-file-rewrite phantom diff (style.css briefly staged as 16,752
  changed lines tonight before being caught). Set `core.autocrlf true`
  before staging anything from a non-Windows git.
- The cloud session's device bridge cannot delete files: stale git
  `*.lock` files get swept into `_to_delete/` (untracked) — empty that
  folder by hand occasionally.
- `tc-ventures-child-theme-pre-git-747` on the server is a pre-clone
  backup of the theme, deletable once trust in the pipeline is restored.
- Carried unchanged from V0.40: postfx bundle order, day-driven bloom,
  applyAtmosphere+instancing, store keys `tcBqTok_v2`/`tcBqLaps_v4`,
  explicit `git add` paths, Edit-tool version bumps, `object-fit/cover`
  never, BHAG = plan-first, purge after every push, PCs + tablets only.
