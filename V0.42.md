## ⚠️ Read first

1. **TWO caches, not one.** The push deployed and `style.css` read 1.0.754
   within seconds, while the homepage kept serving the old HTML — because
   **LiteSpeed's page cache AND Hostinger's CDN** were both holding it
   (`x-litespeed-cache: hit` *and* `x-hcdn-cache-status: HIT`). Purging
   LiteSpeed alone is not enough, and an incognito window proves nothing
   because the staleness is server-side. The fast diagnosis: fetch the page
   with a query string (`/?cb=123`) — a cache-buster bypasses both, so if that
   shows the new markup, the deploy is fine and it is purely cache. **Every
   future "did the deploy work?" starts with that one request.**
2. **`$tc_bq_bg` and `$tc_bq_poster` are two different images with two
   different jobs**, and the comment above them in `front-page.php` says so.
   `$tc_bq_bg` is the **painted map's ground** — `back-quarter.js` measures
   every landmark against that image's own 1280x720 pixel space. Point it at a
   3D render and the map still "works" while sending people to the wrong
   buildings. `$tc_bq_poster` is only the still behind the preview card.
3. **HORSE RIDING is still the queued 3D job** (V0.40). Untouched here.

## What shipped (1.0.754) — on disk

**The order of the homepage is now:** lede strip → the Back Quarter → the pass
hero → the ledger. Thomas's call: the farm is the front door, the photos and
the pass sit directly below it.

- **`.bq-lede`** — new strip above the stage: name, the `<h1>`, one sentence,
  and a *Skip the map* link. **The `<h1>` moved here from the pass hero.**
  Reason it is not laid over the painting: `.bq-preview` is display:none the
  moment `.is-live` lands, so a heading inside it would vanish mid-visit, and
  two display headings over one painted scene fight each other. The pass hero
  keeps its name, deck, menu, CTA and ticket photos — **its `<h1>` element was
  deleted, not duplicated** (`main.js` animates the FIRST `.kinetic-text`; a
  second one would sit at opacity 0 forever — that was the old invisible-H1
  bug in another dress).
- **`.bq-poster`** — the preview still is now a real `<img>` with
  `fetchpriority="high"` and its own dimensions, not a CSS background, because
  it is the page's LCP element. `object-fit: contain`, never cover.
  `assets/img/back-quarter-poster.webp` (1920x1080, 56 KB) is a frame of the
  **3D** world, because that is what the button now opens.
- **The 3D world is the default.** `engageDefault()` picks: 3D on a real
  browser, **the Painted Map** on touch + small screen, and the Painted Map
  when `hasWebGL()` says no.
- **The Painted Map is the fallback and has its own button.** If the 3D engine
  fails to load, the catch no longer apologises — it boots the map.
- **The `#bq3d` gate is gone**, and so is the `Date.now()` cache-bust on the
  postfx bundle and `back-quarter-3d.js`: both now use `?ver=` +
  `tcVentures.ver`, a new field carrying `wp_get_theme()->get('Version')`.
  While it was `Date.now()` the engine was re-downloaded on **every visit** and
  could never be cached — fine for a hidden beta, not for the default.
- **"3D beta" is out of the in-world HUD string** (both the touch and keyboard
  variants).

## Sharp edges

- **⭐ `[hidden]` does not hide a `.tc-btn`.** `.tc-btn { display: inline-flex }`
  beats the UA's `[hidden] { display: none }`. This is why the "Try the 3D build
  (beta)" button — `hidden` in PHP, only un-hidden at `#bq3d` — has in fact been
  visible to **every visitor since it shipped**. `style.css` now carries an
  explicit `.bq-map[hidden]` rule. **Anything else in this theme hidden by the
  attribute alone is worth checking.**
- **P0 numbers, measured on the live 1.0.753 homepage before any of this**
  (headless Chromium, cold): LCP **2.10 s** desktop / **2.10 s** phone, 38
  requests, ~1.84 MB. **The LCP element was `SPAN.hero-ghost`** — the decorative
  faded photo behind the pass hero. Re-measure after the push: the poster should
  take over as LCP, and it is 56 KB against whatever that upload weighs.
- Carried from V0.41: the CRLF working tree (this session's edits preserved line
  endings — verified zero bare LF in `style.css` and `front-page.php`), the
  cloud bridge's inability to delete, LiteSpeed purge after every push.
- The 3D renders fine in headless Chromium with SwiftShader, which is how the
  poster candidates were shot — but software rendering flattens the bloom and
  the grade, so **posters should come from a GPU screenshot**. The one that
  shipped is Thomas's own frame, cropped 16:9 with the UI overlays removed.

### Two things the verification turned up

1. **`three-r128.min.js` is requested before anyone presses anything.** Not the
   Back Quarter's doing — `main.js` idle-loads it for the site's WebGL
   background. Side effect: the 3D world's largest dependency is usually warm
   by the time someone presses the button. Cost: every visitor pays for it,
   including the phone visitors who now get the Painted Map. **Worth revisiting
   now that the homepage is what it is.**
2. **The mouse wheel over a live stage does not scroll the page**, even after
   Esc. Conventional for an embedded 3D scene, but the stage is now hero-sized
   and near the top, so a visitor scrolling with the cursor over it can feel
   stuck. Worth a look: let the wheel through unless the scene is focused.
