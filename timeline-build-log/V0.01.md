## The vision

The `/timeline` page is one continuous parallax scene presenting Thomas's life from 1980 to today as a road trip. The reader scrolls vertically; the world pans horizontally past a side-profile safari jeep pinned center-bottom of the viewport. The jeep has three usable windows: the rear cargo glass holds the prose for the current event, the passenger door window shows a single image, and the windshield is reserved for atmosphere. A curving SVG road runs under the jeep — its bends correspond to biographical inflection points (the divorce, the Township 71 hairpin, the disability redirect). Roadside markers are clickable easter eggs that open a separate "projector" lightbox styled like an 80s home-projector setup at night.

Layers move in alternating horizontal directions (the carnival-duck mechanic), not all the same way — that breaks realism but reads as diorama / stage / memory rather than literal driving. The page deliberately has no footer; it ends at a "Roll-Out" sign.

This page is also the **2D dress rehearsal for the BHAG**. The same jeep, character, sound register, and lightbox aesthetic will move to 3D inside the persistent-canvas topography when the BHAG ships. Thomas confirmed jeep cameo here is intentional compounding.

For the original BHAG vision and how this page bridges to it, see memory `project_tc_bhag_living_document.md`.

## Architecture decisions made so far

- **Vertical scroll → horizontal pan.** Forced horizontal scroll fights browser conventions. The page is one tall scrollable region; transforms on the layers do the panning.
- **Layers, back to front:** sky / backdrop / mid-band / foreground / road. Sky drifts slowest leftward; backdrop leftward; mid-band **rightward** (carnival reversal); foreground leftward fastest; road translates to keep the current event under the jeep.
- **Curving road = single SVG path.** Hand-tuned cubic-Bezier with bends at biographical events. Road translates with scroll; markers are computed each frame from `getPointAtLength()` on the path.
- **Lerp-smoothed scroll.** rAF loop interpolates eased-progress toward target-progress at factor `0.06`. Lerp factor lives in main.js (`initTimelinePage`). Decouples reading rhythm from input cadence.
- **Time-based, not scroll-based, beats.** When the jeep "passes" an event, prose and image cross-fade with a 450ms `setTimeout`. Once a fade starts, it completes regardless of scroll input — reader can't outrun the page.
- **Capsule swap on this page only.** JS injects a year-odometer (interpolating between event years) and a compass needle (rotating with road tangent direction) into the existing `.tc-capsule__clock`. CSS hides the time/zone via `body.page-timeline`.
- **Projector lightbox is its own component, not a PhotoSwipe skin.** Separate aesthetic (night sky + jeep silhouette + pull-down screen + flicker + wobble). Same nav contract (prev/next/escape/swipe). Lives entirely in main.js as `createProjectorLightbox()`.
- **Class names refer to content type, not jeep window position.** `.timeline-jeep__passenger` = the prose box, `.timeline-jeep__rear` = the image box. As of V0.01 the prose actually sits over the *rear* cargo glass and the image sits over the *passenger* door. Names stay; comments in style.css explain.
- **No footer on `/timeline`.** Template skips `get_footer()` and emits `wp_footer()` + closing tags manually. The Roll-Out sign IS the end.
- **Mobile (<768px) skips parallax entirely.** Plain vertical list of all 29 events with the same prose. Don't fight for parallax on phones.
- **Image strategy: faded-Kodachrome photographic backdrops** to harmonize with the photographic jeep. Hand-illustrated would clash. Confirmed by Thomas after the jeep image went photographic.
- **Music: copyright-clear country/folk track, off by default, toggleable, persists in localStorage.** Thomas to source. Not yet wired; lightbox audio is also opt-in.
- **HCS at 1985 is a road bump, not a curve.** The Calgary→Turner Valley *move* is the curve; the diagnosis is the bump on it.
- **Repo is private; deploy via push to main.** Hostinger auto-deploys in ~30s. PAT in remote URL. Push from Thomas's machine works without prompting.

## Running notes (append-only across sessions)

### 2026-04-29 (session 1) — initial scaffold + 5 tuning iterations

- The PHP array in `page-timeline.php` is the source of truth for events. JSON-encoded into a `<script type="application/json">` for JS consumption. Touch the PHP array, not the rendered DOM.
- The road's SVG path is duplicated for the dashed center line. If the road shape changes, both `<path>` elements must update together.
- `getPointAtLength` is reliable but the SVG element's `getBoundingClientRect` shifts every frame as the road translates — recompute scaleX/scaleY each frame, don't cache.
- The CSS class names `.__passenger` and `.__rear` lie about position now (post-swap). Comment in style.css makes the convention explicit: classes refer to *content type*, not window position. Don't rename — JS data attrs would have to change too.
- The original `jeep.jpg` was a flattened JPG (no transparency). Thomas processed background-removal off-site (he didn't say which tool) and uploaded `good-jeep.png`. Aspect ratio matches the original so window coordinates needed only minor tuning.
- After swapping prose-left / image-right, both boxes felt slightly too far left over their target glass. `calc(% + 25px)` shift fixed both with a single offset.
- Lerp 0.06 feels right after Thomas described 0.10 as "too snappy". Pre-resize, the jerky-wheel concern was theoretical; once the page was real he could feel the snap. Keep an eye on this — if anyone complains about lag, dial back to 0.07 or 0.08.
- Page length 600vh → 1100vh was the right call. At 600vh, "one scroll [tick] is a lot on it." At 1100vh, one wheel-tick is roughly one event's worth of scroll, which feels readable.
- **Thomas's working pattern this session:** he generates assets in parallel while I scaffold; then we iterate visually, one tuning per push, with him eyeballing the staging deploy after each. Auto-deploy is fast enough that this works as a real-time loop.
- **Grok image generation took longer than the scaffold.** Backdrops and landmarks are still unwired at end of session. The page motion-tests fully without them thanks to inline SVG silhouette placeholders.
