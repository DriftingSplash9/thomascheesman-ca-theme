## The vision

The `/timeline` page presents Thomas's life from 1980 to today as a road trip. The reader scrolls vertically; the world pans horizontally past a side-profile safari jeep pinned center-bottom of the viewport. The jeep starts full-size, and after the year 2014 (the Township 71 closes era) it shrinks to 21%, slides to the left edge, and rides along the road's curves through the family-photo era. Photos of Thomas's home through the years (2012 → 2022 → 2025 → 2026) crossfade as back-layer images. Per-event imagery drops onto the screen as polaroids — random rotation, random landing spot, hand-drawn caption — and **persists**, drifting leftward as the jeep drives forward, so the album builds up behind the reader. The Roll-Out sign appears at the very end.

This page is the **2D dress rehearsal for the BHAG**. Same jeep, same character, same aesthetic to be rebuilt in 3D inside the persistent-canvas topography when BHAG ships. See memory `project_tc_bhag_living_document.md`.

## Architecture decisions made so far

(Cumulative — most recent first within each section.)

### Entrance / intro section (V0.03)

A full-viewport landing band sits **outside** `.timeline-page` (above the parallax stage). Title `The Long Drive` + subtitle `Forty-six years, one road. Scroll to drive.` + bouncing chevron. Lives in `.timeline-intro`. Because it's outside the main, its height does NOT add to the parallax progress range; the user scrolls past it cleanly, then the stage begins.

### Page length (V0.04)

`--tl-length: 4000vh` (was 2000vh). Doubled to give events more breathing room and let the polaroid drift system pile up imagery on screen.

### Jeep-on-road math (V0.05)

JS samples the road's y at the jeep's center via 16-iteration binary search of `getPointAtLength()` to invert the path's arc-length parameterization. Sets `--jeep-road-y` to that y in vh-from-bottom. CSS uses `bottom: var(--jeep-road-y, 6vh)` directly — **no offset**, because the actual jeep PNG's wheels touch the image bottom (only 0.2% empty space — measured from the file). Earlier offsets (0.08 × box height, 0.15 × box height) over-corrected because they assumed empty space below the wheels that doesn't exist.

### Jeep handoff at year 2014 (V0.03 → V0.05)

Jeep stays at full size from start until pos 0.74, then **shrinks + slides left + follows road** over progress 0.74 → 0.78 (just after "Township 71 closes"). End scale 0.21, end position `left: 10vw`. Window was originally 0.65 → 0.70 (V0.02); shifted later in V0.03 so T71's prose window happens during the full-size jeep era — otherwise the marker sat 65vw to the right of the shrunk jeep and never visually met it.

CSS: `--jeep-shrink: clamp(0, calc((var(--tl-prog-eased) - 0.74) * 25), 1)`.
JS uses the same shrink curve to compute `jeepCenterVw = 50 - shrink * 40`.

### Compass — bearing-driven (V0.04)

Each event has an optional `bearing` field (degrees, 0=N, 90=E) representing the direction Thomas was heading from the previous event's location to this one. Stationary events (HCS diagnosis, kitchen-mgmt years, kids born — anywhere he didn't move) inherit the previous bearing automatically (init pass in JS). Bearing values populated for 12 events covering all major moves:

| 1990 TV → Teepee Creek               | 330°    | NNW       |

The needle lerps toward the current event's bearing each frame (5% per-frame factor) with shortest-path interpolation that handles 0/360 wrap. Falls back to road-tangent direction only if no bearing data exists in the event chain. The old "lock to north at progress 0.55" rule from V0.02 is gone.

### Polaroid system — persistent + drift (V0.04)

Every event with a populated `image` field renders its own `<div class="timeline-polaroid">` server-side in `page-timeline.php`. Random rotation (-8°..+8°), landing x (28..72vw), landing y (26..58vh) are baked in deterministically from the event index — same on every reload, different from neighbors.

JS reads `data-polaroid-trigger` (set to the previous event's pos) on each polaroid each frame:
- `elapsed < 0`: hidden (above viewport via class state).
- `elapsed >= 0`: `.timeline-polaroid--active` class added → CSS transition drops the polaroid into its landing pose.
- After ~0.005 progress: JS sets `--polaroid-drift` per frame to `(elapsed - 0.005) × 350vw`. The polaroid slides leftward off-screen as scroll continues.

Multiple polaroids visible at once. A polaroid clears the viewport over roughly 5–6 events at the 4000vh page length. Caption currently shows the year (`evt.year`); see todos for the WP-caption-field wiring.

### Night sky fit + tile feathering (V0.05 → V0.06)

`background-size: 100vw auto` + `background-repeat: repeat` so a single tile is sized to the viewport (was `cover` against the 200vw extended layer = scaling stars ~3× too big). `filter: blur(1.2px)` on the strip to soften tile-to-tile seams. The "proper" fix is a seamless tileable starscape PNG; the blur is the no-asset-change version. Term-of-art for the blur is **edge feathering** / **alpha feathering**.

### Road geometry (V0.06)

Path span: vbx 0 to 12000. Lead-in `M -4000 540 L 0 540` and lead-out `M 12000 540 L 16000 540` extend the visual road past the event range. Y range pulled in to 440–540 (was 200–560 mid-V0.04). Reasoning: with the jeep tightly road-following, big y excursions made the jeep fly across the viewport vertically. 10vh swing is ample dramatic without making the page feel chaotic.

Shape, in geographic order:
- **Foothills hump** (vbx 0–800): single bump up and back down, matching Calgary → Turner Valley.
- **Prairie flat** (vbx 1400–2800): roughly y=540, matching Teepee Creek / Edmonton / Le Glace / Pig Farm prairie years.
- **Little Smoky hill** (vbx 3200–4400): the genuinely hilly section, peak around y=440 matching the 1997–99 boreal-forest era.
- **Rolling middle** (vbx 4800–8800): gentle wave through GP era, Fort Mac trip, kitchen-mgmt years.
- **Settled end** (vbx 9200–12000): smooths back to flat for the home era.

Both road `<path>` elements (main + dashed center line) carry the same `d` — keep them in sync if you re-tune.

With `background-size: contain` + `position: bottom`, the image bottom = box bottom, so the wheels are effectively at the box bottom — no offset needed at all. **Lesson for future tunings: when a guess about an image asset's internal proportions feels wrong, just measure the file.**

- **Polaroid persistence** was a bigger win than I expected. Going from "single polaroid swaps each event" to "polaroids drift left and pile up" reads as a craft-album building up rather than a slot machine. The deterministic randoms (rotation/pos derived from event index) keep the chaos consistent across reloads.
