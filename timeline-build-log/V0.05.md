## Architecture decisions made during this session

(Cumulative on top of V0.04 — most-recent first within each section. Marked PARKED throughout for items that were abandoned.)

### Entrance phase (V0.07)

The first 5% of timeline progress (`ENTRANCE_PHASE = 0.05`) was a no-scene-pan zone where only the jeep moved. Jeep slid from `left: 0vw` to `left: 50vw` (viewport center) on a quadratic ease-out so its velocity reached zero at the transition; scene then ramped from zero via a quadratic ease-in over `SCENE_RAMP = 0.025` of progress (~100vh of scroll). At the transition, both jeep and scene velocities meet at zero — no jump. Drag-racer wheelie tilt schedule on top of that motion: -45° (0–0.30 of entranceProgress) → -30° (0.30–0.50) → -45° (0.50–0.80) → smooth -45→0° (0.80–1.0). Pivot at the rear wheel (transform-origin 25% 100%) during entrance, reset to 50% 100% post-entrance for the home-era shrink.

`raw EasedProgress` accumulates the lerp; outer-scope `easedProgress` and `entranceProgress` are recomputed from it each tick. Wheel spin uses the raw derivative so wheels still spin during entrance even though `easedProgress` is pinned at 0.

### Road shape — 3 explicit Q bumps (V0.05+++.4)

After three coord-conversion fixes the jeep was still acting nuts on small bumps. Replaced 14 chained Bezier S segments (which produced compounding local tangent wildness) with 3 explicit Q-quadratic bumps at vbx 800–1400, 4000–4800, 8000–8800, separated by L straight sections:
```
M 0 540
L 800 540  Q 1100 510, 1400 540
L 4000 540 Q 4400 500, 4800 540
L 8000 540 Q 8400 510, 8800 540
L 12000 540
```

### Road CSS offset — `-50vw` (V0.07.1)

Shifted the road's `transform: translate3d(calc(-50vw - var(--tl-pan-road) * var(--tl-prog-eased)), 0, 0)` from the prior `-25vw`. Path-progress P now sits at viewport-x **50vw** (jeep center) directly. JS jeep math: `jeepF = easedProgress` (no `- 0.0833` offset). Also fixes the entrance-end teleport (jeep was at 50vw at entrance end but path-clamp put it at 75vw post-entrance).

### Coord conversion — naive scale wins despite slice (V0.05+++.3)

The SVG declares `preserveAspectRatio="xMinYMax slice"` which technically forces uniform scale at `max(naiveX, naiveY) = 1.08 px/unit`. But the road's CSS layout was designed against the **naive scale** (`rect.width / vbox.width = 0.48 px/unit`). Browsers seem to honor the CSS dimensions and render the path at naive scale when CSS dimensions are explicit. Using `getScreenCTM` ("technically correct") puts the jeep at the technically-right scale, but the road is rendered at the naive scale, so the jeep ends up several thousand pixels off-screen. **All position calcs use the naive scale.** Tangent angle is computed in screen space via `atan2` of pixel deltas after the slice scaling — capped at ±10° so wild local Bezier tangents can't tip the jeep over.

### Backdrop chain — Price is Right → Keg Family → Night Sky (V0.06.4)

Thomas's chronological order: `keg-price` fades in 0.50–0.54 (z=5), `keg-family` fades in 0.56–0.60 (z=6), `night-sky` fades in 0.60–0.62 (z=7, brief — addresses earlier "soo much night sky" complaint), home photos take over at z=8–11. All `no-repeat` with dark fill on the sides. Single instance per backdrop — Thomas: "I don't want any background tiled or duplicated."

### Home photo crossfade (V0.06)

Adjacent home slides now ramp 0 (at prev center) → 1 (at own center) → 0 (at next center) — at the midpoint between centers, both slides are at 0.5, summing to 1.0. True crossfade, no hard cuts through the backdrop between slides. Last slide holds at 1 past its center.

### Highway signs — real-highway layout (V0.05+ Polish)

Place name left, distance right, with space between. Split single `text` field into `text` (name only) + new `distance` field per mark. PHP renders two spans inside `.timeline-marker__text`; CSS makes container `flex; justify-content: space-between`. Distance gets slight letter-spacing so it reads as a figure. Stagger fix: Major's offset 160 above Township 71 (offset 0); Teepee Creek offset 160 above Turner Valley (offset 0).

### Major's / Tractor Jack's logos

`majors-homestyle-logo.png` on the green sign's photo slot; `tractor-jacks-logo.png` as the polaroid for the 2015-21 event. Sign photo slot CSS rewritten to `height: 132px; width: auto; max-width: 240px; object-fit: contain; background: transparent` so the wide MAJOR'S wordmark renders in full instead of cropping.

#### Pattern this session
Heaviest iteration session yet. Thomas in fast-iteration mode with Hostinger auto-deploy + push cadence. Many commits per problem; willingness to revert. Each visible glitch on staging triggered a tight push-eyeball-fix loop.

#### Footguns from this session

1. **Cache-buster ≠ deploy.** Bumped commit message claimed `1.0.153 → 1.0.154` but the `Version:` line in style.css stayed at 1.0.153. Browsers re-served the pre-spike main.js. The bumping is a separate edit from the commit text — always verify `Version:` actually changed.

2. **MotionPathPlugin angle is path-local.** `MotionPathPlugin.getPositionOnPath(rawPath, progress, true).angle` returns degrees in the path's local coord system. For a path with viewBox 20000×600, dy/dx is tiny even when the visual on-screen tangent is steep. Don't trust the angle field for screen-space rotation.

3. **getScreenCTM is "right" but doesn't match intent.** With `preserveAspectRatio="xMinYMax slice"` and explicit CSS dimensions, browsers render the path at the naive `rect.width/vbox.width` scale, not the slice-uniform scale. CTM gives the latter; the road's CSS is designed against the former. Use the naive scale to match the road's actual visual layout — even though it's "technically wrong."

4. **Wild Bezier tangents tip the jeep over.** Chained S commands produce locally steep tangents at certain progress points. Cap displayed angle to ±10° even when sampling the path correctly. Better: simplify the path to explicit Q bumps with L straight sections in between.

5. **Sprites read as bolted-on.** Whatever clever attachment scheme you use (poles, stakes, hanging clips, top-parallax drift), individual decorative sprites scattered along a road feel disconnected from the narrative. Photographic mid+fore layers (continuous panorama) read better. And eventually even those got replaced by the passport metaphor entirely.

6. **Page-turn metaphors require a different mental model than a road trip.** The jeep build was scroll-driven horizontal pan with one centerpiece vehicle. The passport build is scroll-driven vertical page-flips with stamps on each page. Different design language; very little CSS/JS reuse between them.

7. **A "real" passport stamp is varied.** Don't ship 4 fixed types. Real passport stamps mix shapes, colors, text-only, half-impressions, smudges, off-axis placements. The 4-type cycle in commit 2 of the passport is a placeholder pending the next-conversation refinement.
