## ⚠️ READ THIS FIRST — full pivot incoming

**Both prior approaches are parked. The next agent is starting from scratch.**

The `/passport` build (which itself replaced the parked `/timeline` jeep build) was **3 of 4 commits in** when Thomas decided the metaphor was wrong: stamps and photos are conceptually different. Real passport stamps are **ink-only marks** — outlines, shapes, colors, text, simple emblems (coats-of-arms, mountains, animals, planes). They are NOT photo frames. The current implementation crams a photo inside a circular ink ring on every page; that conflates two distinct things and reads as neither stamp nor photo.

Reference images Thomas shared (real passport spreads + a passport-stamps stock sheet) make this obvious: real stamps mix ovals, rectangles, triangles, hexagons, double-rings; varied inks (red, blue, indigo, oxblood, teal, sepia, black, purple); always text-and-emblem, never photo-bearing.

### Direction for V0.06+

- **Photos are presented AS photos** (polaroids, prints, photo-corners on paper, scrapbook clippings, etc.) — never inside an ink-stamp ring
- **Stamps, if used at all, are ink-only** — outlines, shapes, text, simple emblems — purely decorative
- **The footer already has a passport** — duplicating that on a main page is redundant
- **New direction is a SCRAPBOOK** (or scrapbook-like surface). Surface metaphor (wood table / desk / bed / podium / something else) is **TBD pending Thomas's decision**
- **For now use the wood-table background** that the footer passport already uses (`/wp-content/uploads/2026/04/passport-bg.png`) as the surface placeholder, until Thomas commits to a final surface

```
0: red     (#8b1a1a) -3deg  0   0   op 0.97
1: blue    (#1a3a8b)  5deg  -2  -4  op 0.92
2: indigo  (#1e3a5f) -6deg   3   3  op 0.95

```

Slot derivation: `($page_num + $stamp_idx) % 6`. Adjacent pages don't share an ink. Across 50 events, each color appears ~8 times.

#### Key insight to preserve

**A stamp is a stamp; a photo is a photo.** Crossing them produces a thing that's neither. When the next agent designs the scrapbook, this is the rule that frames every element: each visual element should be one thing, recognizably itself. A polaroid looks like a polaroid; a stamp looks like a stamp; a ticket stub looks like a ticket stub. Don't combine.

#### Why the passport idea was tempting but wrong

The footer already does a passport metaphor well — and it works there because the footer passport doesn't try to display photo content; it's mainly identity chrome (cover, MRZ, signature, page number) with small stamps as accents. When the same metaphor was lifted to a content page (50 events, each with photos), it broke: the photo became the primary content but had nowhere natural to live in a real-passport visual language. So we put it in the stamp ring. That's the conflation.
