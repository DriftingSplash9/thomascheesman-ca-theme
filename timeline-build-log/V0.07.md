### Page-number circles (one per era)

Each circle: r=22, stroke-width=2.8 (thicker outline), `drop-shadow(1.5px 2.5px 2.5px rgba(0,0,0,0.4))` to lift it off the paper, light tinted fill at 0.10–0.13 fill-opacity, font Special Elite size 18 bold inside the ring. SVG should use `viewBox="-2 -2 64 64"` so the drop shadow doesn't clip.

### Page-number easter eggs (CSS animations, JS for randomness)

Each page number has a unique hover effect. **All five are documented in the demo file's `<style>` and trailing `<script>` block** — copy them verbatim into the production scrapbook CSS/JS.

| Page (era) | Effect | Random params (JS) |

### Decade tabs (navigation)

Five horizontal tabs, primary = era ink, secondary = era design language:
- **1980s · indigo** — indigo base + Memphis pattern overlay (neon dots/squiggles)
- **1990s · oxblood** — oxblood base + arrow-tip two-tone split + neon yellow text
- **2000s · sepia** — sepia chrome gradient (light tan → deep sepia → tan), italic text
- **2010s · black** — flat charcoal, hairline white accent, light Helvetica
- **2020s · forest** — **glassmorphic** — semi-transparent forest tint, white edge, top-shine reflection, soft drop shadow

Tabs should be sticky in the top margin while flipping pages (or in the header bar — pick what reads cleanest).

## 🏗️ Architecture

### Page-flip mechanic (CSS-only, no video)

```
.scrapbook
  perspective: 1500px;
  position: relative;

  .scrapbook-book
    transform-style: preserve-3d;
    /* the open book — left + right pages visible */

    .scrapbook-page-stack
      /* multiple .scrapbook-page elements, each absolute positioned,
         hinged at left or right edge depending on side */

      .scrapbook-page
        transform-origin: left center;  /* for right-side pages */
        transition: transform 0.8s ease-in-out;
        backface-visibility: hidden;

      .scrapbook-page.flipped
        transform: rotateY(-180deg);
```

State machine in JS:
- Track current spread index (0 to ~56)
- "Next" → flip the topmost right-side page from rotateY(0) to rotateY(-180deg)
- "Prev" → flip the topmost left-side page from rotateY(-180deg) to rotateY(0)
- Decade tab click → instant-jump multiple pages (skip animation, or stage a quick batch flip)
