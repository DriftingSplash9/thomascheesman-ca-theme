## Feature inventory (everything currently shipped)

### Layout / typography
- Hero with script-font "Timeline" + dad's letter (with Layton quote)
- Per-decade period frames on every photo: 80s mahogany w/ brass mat,
  90s neon w/ memphis dots, 00s glossy Web 2.0 button, 10s Polaroid w/
  caption stripe, 20s glassmorphism w/ light-sweep
- Up to **3 images per event** rendered side-by-side in their frames
- Image-row breakout — text stays in narrow reading column,
  image rows extend to nearly full viewport width via negative margin
- Drop caps on first event note of each chapter
- Sticky chapter chip pinned during chapter scroll
- Chapter nav pills + size-rank chapter ink palette
- Year-density SVG bar chart (click any year → jump)
- Year scrubber (right edge, drag to scroll proportionally)
- Search box that floats top-center → bottom-left as you scroll
- Custom 404 page

### Atmosphere
- Multi-layer parallax blob field (chapter-tinted, drift on scroll)
- Canvas-based particle field — 30 specks, blurred, drift up with
  per-particle wandering heading, cursor attracts most + 2% rogues
  flee, 2-4 mutating connections per particle (drop random + top up)
- Chapter tint cross-fade + browser theme-color sync
- Animations respect `prefers-reduced-motion`

### Audio (per-decade radio)
- 80s → **All Classical Portland** (in tribute to Thomas's father,
  loved Bach/Mozart) — direct mp3 stream, no HLS overhead
- 90s → Big Country 93.1 GP
- 00s → 97.7 Rock GP
- 10s → 98.9 Rewind GP
- 20s → Sun FM 96.3 (placeholder URL = 97.7 Rock until real Sun FM
  stream URL is found by Thomas via DevTools on sunfm.com)
- HLS.js for Chrome (worker thread, 60s buffer, auto-recovery on
  network/media errors)
- Crossfade between stations on decade boundary (1.4s out → swap →
  1.4s in)
- URL guard prevents stream rebuild during scroll wobble
- Default volume 25% (was startling at 100%)

### Map (`/map`)
- Dark Mapbox auto-framed to fit Thomas's 29 places
- Pins coloured by chapter ink (size-rank palette)
- Click a pin → popup listing events at that location, deep-linked
  back to `#event-N` on timeline
- 4 places aliased server-side (Home Sweet Home, The Keg, Major's,
  Big Berland) so they pin at Grande Prairie / hardcoded coords

### Slideshow mode
- ▶ Slideshow button top-right
- Requests fullscreen + auto-scrolls through every event
- Hold time scales with note length: 6s base + 25ms/char, capped 16s
- Two-column stage (image left ~58%, text stack right)
- Article breaks out of regular `max-w-3xl` constraint
- Photo capped at 75vh + 8vh bottom padding so period frames don't clip
- Fade-in animations disabled mid-slideshow
- Esc / button click / fullscreen exit → stops cleanly
- Filtered events (search active) are skipped

### Performance budget
- Slow-device detection (≤2 cores / ≤2 GB RAM / data-saver) drops
  particle field + back blob layer + text slide-ins
- Mobile media query (max-width 640px) does the same
- `will-change: transform` + `translateZ(0)` on photos for GPU layers
- Worker thread for HLS audio decoding
- Lazy-loading on all `<Image>` components

### PWA / SEO
- Web App manifest, custom favicon ("T" mark, violet on dark)
- Apple touch icon (180×180 generated via @vercel/og)
- Service worker (production only, minimal — for install affordance)
- Open Graph share card auto-generated at `/opengraph-image`
- Custom 404 with link back to `thomascheesman.ca`

### xlsx source-of-truth + tooling
- 143 events, 9 eras (canonical order — including renamed
  "The Temporary Migration South")
- Headers: # / Year / Order / Era / Place / Title / Note /
  Image / Image 2 / Image 3 / Preview / Preview 2 / Preview 3
- 141 50×50 thumbnails embedded in K/L/M for visual scanning
- Cool palette applied: smallest era = pronounced blue,
  middle = indigo/violet, biggest era (New Restaurants, 46 events)
  = strong emerald green
- `ink-by-era.json` sidecar so Python script + Next.js app share
  the same era → hex mapping
- Place name normalisation built-in (LaGlace → La Glace, gp → GP,
  Hope BC → Hope, BC, etc.)
- Within-year sub-ordering via column C ("Order")
- Backup auto-saved with timestamp before each restyle run

### Editor workflow
```bash
# After editing the xlsx:
node scripts/import-events.mjs       # → src/data/events.ts
node scripts/geocode-places.mjs      # → src/data/places.ts (only if new places)
python scripts/restyle-xlsx.py       # → restyle xlsx + refresh thumbnails
                                       (only after big batches; normally skip)

# Then push via GitHub Desktop → Vercel auto-deploys in ~60s
```
